01 / 简单、限时、可确认

让 Mac 专注于正在做的事。

Perky 的基础模式只处理一件事：阻止系统因空闲而自动睡眠。屏幕仍按你的 macOS 显示器设置关闭。

01

选择一个时长

从 15、30、60 分钟快捷选项开始，也可以设置 1 到 1440 分钟的自定义计时。

02

查看当前状态

菜单栏面板展示运行状态与剩余时间。计时基于截止时间，面板关闭后也会继续。

03

到时自动结束

可以提前停止或延长。到期后 Perky 释放自己的保持唤醒断言，让 Mac 恢复原有睡眠行为。

02 / 两种模式，边界清楚

只用你需要的那一种。

基础防空闲睡眠不等于合盖运行。需要合盖时，再单独查看授权与设备条件。

03 / 先看设备与系统

Perky 适用于 Mac，不是 Windows 笔记本工具。

当前版本是原生 macOS 应用。基础模式与合盖模式有不同要求，请按实际运行的操作系统判断。

设备或系统当前支持情况
运行 macOS 14+ 的 Mac基础定时保持唤醒
Mac 合盖运行需恢复 helper；行为因环境而异
RedmiBook、Redmi / Xiaomi 笔记本Windows 版本不支持
华为 MateBook、ThinkPad 等 Windows PC当前版本不支持

关于合盖模式：首次使用需要 Apple 信任签名及在 macOS 系统设置中批准恢复 helper。接入电源、外接显示器、低电量保护和具体机型都会影响合盖后的行为；Perky 会在无法确认时显示限制，不承诺所有机型均能合盖运行。

04 / 常见问题

开始前，先弄清楚这些。

Perky 支持 RedmiBook 或 Redmi 笔记本吗？

不支持。Perky 当前是原生 macOS 应用，面向运行 macOS 14 或更新版本的 Mac；运行 Windows 的 RedmiBook、小米笔记本及其他 Windows PC 不能运行此版本。

所有 MacBook 合盖后都能继续运行吗？

不能保证。合盖模式需要单独授权恢复 helper，且实际效果与机型、macOS 版本、供电及外接设备有关。请以应用内的兼容性检查和系统状态为准。

基础模式会让屏幕一直亮着吗？

不会。基础模式只阻止系统因空闲而睡眠，显示器仍按照你在 macOS 中设置的时间关闭。

可以在哪里获取 Perky？

目前仓库提供源码和构建脚本，尚未提供已签名的下载发行包。请在 macOS 14+ 上按仓库的构建说明制作应用。
