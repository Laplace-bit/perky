01 / MacBook 合盖运行方式

先区分外接屏幕与无屏方案。

Apple 支持的外接显示器桌面模式与 Perky 的无外接屏幕实验性覆盖是两条不同路径。Perky 另有全局电源回退，所有临时设置都需要按记录恢复。

01

外接显示器 · Apple 支持

Apple 支持 MacBook 连接外接显示器及所需输入配件后合盖使用。具体供电、显示器与配件要求以你的机型为准。查看 Apple 使用说明。

02

无外接显示器 · 实验性 IOKit

macOS SDK 中存在相关 IOKit selector，但 Apple 未承诺第三方 App 可依赖。效果会因 Mac 机型和 macOS 版本而异，不保证所有设备可用。

03

系统级回退 · 记录并恢复

pmset -a disablesleep 是影响整台 Mac 的全局设置。Perky 记录原值并在会话结束后恢复；无法确认恢复时会保留记录并提示处理。

02 / 合盖路径与系统边界

合盖运行有条件，基础模式不等同。

Apple 外接显示器桌面模式由系统支持；无外接屏幕时属于实验性覆盖。开盖基础防空闲睡眠是另一种功能。

03 / 先看设备与系统

Perky 面向 MacBook；Windows RedmiBook 不支持。

Perky 是原生 macOS 应用。Apple 支持的外接显示器合盖桌面模式与无外接屏幕实验性 IOKit 覆盖有不同要求，请按设备和操作系统判断。

04 / 常见问题

开始前，先弄清楚这些。

MacBook 合盖连接外接显示器时可以继续使用吗？

Apple 支持在 MacBook 接入外接显示器及所需键盘、鼠标或触控板后合盖使用。具体供电、配件和机型要求请看 Apple 支持文档。Perky 对合盖会话另行检查外接显示器与供电条件。

没有外接显示器，Perky 也能在 MacBook 合盖后继续运行吗？

Perky 提供实验性的 IOKit 合盖覆盖。macOS SDK 中存在相关 selector，但 Apple 没有承诺第三方 App 可依赖此接口；兼容性会随机型与 macOS 版本变化，不能保证所有 MacBook 均可用。GitHub 安装包会请求管理员认证并安装本机恢复 helper；该安装包没有 Apple 公证，首次启动可能需要手动通过 Gatekeeper。

pmset 回退会改动整台 Mac 吗？

会。pmset -a disablesleep 会设置全局系统级防睡眠状态。Perky 记录启用前的值，并在会话结束时恢复；若无法确认恢复或检测到系统设置被其他程序改动，会保留恢复记录并提示处理。

Perky 支持 Windows RedmiBook 或 Redmi 笔记本吗？

不支持。Perky 是原生 macOS 应用，运行 Windows 的 RedmiBook、Redmi / Xiaomi（小米）笔记本及其他 Windows PC 不能运行此版本。

开盖基础模式等同于合盖运行吗？

不等同。开盖基础模式通过 macOS 电源断言阻止系统因空闲而睡眠，显示器仍按 macOS 设置关闭；它本身不覆盖 MacBook 合盖行为。

可以在哪里获取 Perky？

GitHub 发布版本后，可从 GitHub Releases 获取本机管理员安装包。安装时需管理员认证；安装包未经过 Apple 公证，macOS 可能要求你在“系统设置 > 隐私与安全性”中手动允许打开。也可以查看源码，在自己的 Mac 上构建。
