01 / MacBook 合盖运行方式

合盖运行，靠可验证的系统设置。

Perky 使用系统级 SleepDisabled 防止合盖睡眠，并在每次启动后用 pmset -g 验证；外接显示器桌面模式仍遵循 Apple 支持条件。所有临时设置都会按记录恢复。

01

系统级防睡眠 · 合盖继续运行

本机恢复 helper 执行 pmset -a disablesleep 1，阻止合盖和空闲睡眠；Perky 会验证设置已生效，并在会话期间持续复查。

02

外接显示器 · Apple 支持

连接外接显示器及所需输入配件后合盖使用是 Apple 支持的桌面模式。具体供电、显示器与配件要求以你的机型为准。查看 Apple 使用说明。

03

限时恢复 · 失败不覆盖

系统级设置会影响整台 Mac。Perky 记录原值，在停止、到期或安全停止时恢复；若设置被外部改动，会保留记录并提示你选择处理方式。

02 / 合盖路径与系统边界

合盖运行有条件，基础模式不等同。

系统级防睡眠会同时影响合盖与空闲睡眠；外接显示器桌面模式由系统支持。开盖基础防空闲睡眠是另一种功能。

04 / 常见问题

开始前，先弄清楚这些。

MacBook 合盖连接外接显示器时可以继续使用吗？

Apple 支持在 MacBook 接入外接显示器及所需键盘、鼠标或触控板后合盖使用。具体供电、配件和机型要求请看 Apple 支持文档。Perky 的合盖会话会另行检查电量与安全停止条件。

没有外接显示器，Perky 也能在 MacBook 合盖后继续运行吗？

可以。Perky 通过管理员安装的本机恢复 helper 临时启用系统级防睡眠（SleepDisabled），并用 pmset -g 验证生效；停止、到期或触发安全条件时恢复启用前的值。GitHub 安装包会请求管理员认证并安装 helper；该安装包没有 Apple 公证，首次启动可能需要手动通过 Gatekeeper。

pmset disablesleep 会改动整台 Mac 吗？

会。pmset -a disablesleep 会设置全局系统级防睡眠状态。Perky 记录启用前的值，并在会话结束时恢复；若无法确认恢复或检测到系统设置被其他程序改动，会保留恢复记录并提示处理。

Perky 支持 Windows RedmiBook 或 Redmi 笔记本吗？

不支持。Perky 是原生 macOS 应用，运行 Windows 的 RedmiBook、Redmi / Xiaomi（小米）笔记本及其他 Windows PC 不能运行此版本。

开盖基础模式等同于合盖运行吗？

不等同。开盖基础模式通过 macOS 电源断言阻止系统因空闲而睡眠，显示器仍按 macOS 设置关闭；它本身不覆盖 MacBook 合盖行为。

可以在哪里获取 Perky？

从 GitHub Releases 下载最新的 Apple Silicon（arm64）安装包。先登录桌面，双击 .pkg 并输入管理员密码；安装器会写入 Perky、root 权限的本机恢复 helper 和 LaunchDaemon。若 Gatekeeper 拦截，请到“系统设置 > 隐私与安全性”选择“仍要打开”，不要关闭 Gatekeeper。打开 Perky 后点击菜单栏图标，选择时长并开启“合盖运行”；等面板确认系统级防睡眠已生效后再合盖。停止、到期或触发安全条件时会恢复系统设置。安装包未经过 Apple 公证，Intel Mac 需自行从源码构建。
